    How do I export from Anki?
    1. In Anki, open Browse and select the deck (or the cards) you want.
    2. Choose File → Export (or Notes → Export Notes).
    3. Pick Notes in Plain Text (.txt). Turning off “Include HTML and media references” gives the cleanest result.
    4. Drop the exported file here. The first field becomes the front, the second the back.
